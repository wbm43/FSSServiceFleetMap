How to read this map

Real province geometryProvince outlines are the actual Dutch province boundaries. Each site's dot is placed at a random point inside its assigned province's real shape — not its true coordinates, since neither source file contains GPS data.
Region = best-effort matchRegion was inferred from the city named in each address, matched against known Dutch geography (no live geocoding was available in this environment). 823 sites matched directly with high confidence; a further 103 were resolved through a follow-up address-research pass. Only sites with a resolved region are shown on this map.
76 sites aren't shown hereThey have no usable address on file, so there's no region to place them in (1 more turned out to be a Germany-based entity address, also excluded from this map). See the data-gaps workbook for the full list and suggested next steps.
"Type not known" ≠ "no address"The gray dots are sites where the install type (ground-mount / tilted / BESS) was never recorded — a separate gap from having no address. Most of them DO have a known location and a working Google Maps link; only the address gap keeps a site off this map entirely.
"DC-side" = install type proxyNeither file has a per-site service-history field, so ground-mount + tilted sites (with a PV array) stand in for the DC-side inspection population; BESS-only sites are excluded.
Urban/rural = general knowledgeProvince hover cards use a well-known characterization of that province, not measured local population data — no census source was reachable from this environment.
